# 传统规则对照

核对日期：2026-10-15。参考的是《大富翁4》，没有混用美式 Monopoly 的凑齐色组后统一盖房、双骰连掷等规则。

一手资料：

- [大宇在 Steam 发布的游戏说明](https://store.steampowered.com/app/2059810/?l=schinese)。
- [Steam 官方页面链接的游戏手册](https://store.steampowered.com/manual/2059810)：纸面第 11、14、18、19 页。手册仅供核对玩法，未复制其人物、插画或程序实现，也未把手册文件提交到本仓库。

| 核对项目 | 资料中的规则要点 | 当前实现 |
| --- | --- | --- |
| 地产建设 | 住宅逐次加盖，最高五个等级 | 支持 0–5 级，最高级拒绝继续升级 |
| 路段经营 | 同路段产业联合计算租金 | 用地图的四个街区映射路段；同一地主、同一街区联合计租 |
| 银行 | 经过可存取款，停留另有贷款业务 | 经过与停留均可存取款，途中办理后继续走完骰子；贷款尚未实现 |
| 公园 | 提供安全休息的位置 | 不额外收租或发现金 |
| 医院 | 住院时失去收租权 | 暂停行动期间不收租，访客也不会因此消耗免租卡 |
| 手持卡片 | 手持卡片上限为 15 张 | 使用相同上限，当前实现四种原创卡片 |
| 股票 | 通过菜单买卖，而不是只在股市格交易 | 通过股市面板买卖；当前仅在自己回合开始或结束时交易 |

## 学习版保留的简化

这次对照调整核心互动方式，没有声称完整兼容原作：

- 使用 20、30、50 天短局，利率、地价、租金倍率、税费、过圈奖励与事件数值为本项目设定。
- 存款每日利息为 1.5%，没有实现原作完整日历、周末休市或银行休业。
- 股票仍用现金按每次 10 股交易，没有实现董事长、公司盈余、涨跌停和借贷。
- 卡片商店使用现金，未实现原作点券与完整卡片、道具体系。
- 资金不足时自动取存款、卖股、七折卖地，没有实现拍卖与玩家交易。
- 地图、人物、房屋和声音均为原创，未包含原作资源。

电脑采用常见的地产经营策略：保留应急现金、优先形成同街区资产、在银行准备现金、根据前方风险与升级收益使用卡片。这些是本项目的策略实现，不声称还原了原版电脑 AI。
